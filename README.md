# Nguyen Dang Dat (@arcrek) — Portfolio

A high-performance developer portfolio built with **Astro 7**, **Tailwind CSS v4**, and a custom **Architectural Material 3 (M3) + Editorial Engineering Hybrid** design system, deployed on **Cloudflare Pages** at **[datnd.io.vn](https://datnd.io.vn)**.

Written from the perspective of an ICT student and systems builder from Vietnam passionate about self-hosting, protocol reverse-engineering, and backend tooling.

## Key Features

- **Architectural Material 3 (M3) + Editorial Engineering Hybrid Design System**:
  - M3 Tonal Cobalt-Slate surface palette (crisp slate-tinted light mode & deep slate/electric sky dark mode) pairing `rounded-3xl` outer containers with preserved `1px` internal editorial hairlines and `rounded-full` M3 expressive pill controls.
  - Interactive SVG system architecture pipelines (`ArchitectureDiagram.astro`) with `rx="12"` rounded diagram nodes, animated data-flow connectors, and stage inspection readouts.
  - Hybrid hierarchy: expanded Flagship Systems (`FlagshipCard.astro`) paired with a compact, single-line expandable Engineering Index (`ProjectRow.astro`).
  - Zero-FOUC theme toggle and Astro `<ClientRouter />` View Transitions.
- **Focused Page Architecture**:
  - **Engineering Index (`/`)**: Masthead with integrated stack strip, 2 flagship production systems (`TMail`, `Telegram Order Bot`) with interactive SVG pipelines, and 5 expandable repository rows (`Xray VLESS Go`, `Outlook Graph Module`, `Canva Automation Suite`, `VMS`, `price_board`).
  - **Lab [Hobby] (`/lab`)**: Distinct, deduplicated hobby page showcasing the self-hosted homelab network topology (Proxmox VE, TrueNAS, Traefik, AdGuard Home, Docker, Jellyfin) and 2 a.m. builder workflow.
- **Build-Time GitHub Hydration**:
  - Languages, topics, stars, and repository metadata are fetched at build-time with offline cache fallback (`src/lib/github.ts`).
  - Privacy filter ensures only public, verified repositories are displayed.
- **Near-Zero Client JavaScript**:
  - Static HTML output generated by Astro with lightweight vanilla JS for SVG node inspection and zero UI framework overhead.
- **Cloudflare Pages Ready**:
  - Configured with `wrangler.jsonc` and `public/_headers` for edge caching and security headers.
  - Continuous deployment via Cloudflare Pages Git integration or GitHub Actions (`.github/workflows/cloudflare-pages.yml`).


### 5. Deploy to Cloudflare Pages via CLI
```bash
npx wrangler pages deploy ./dist --project-name portfolio
```

## Deploying to Cloudflare Pages with Custom Domain `datnd.io.vn`

### Method 1: Cloudflare Git Integration (Recommended)
1. Go to the [Cloudflare Dashboard](https://dash.cloudflare.com/) > **Workers & Pages** > **Create application** > **Pages** > **Connect to Git**.
2. Select repository `arcrek/portfolio`.
3. Set the build configuration:
   - **Framework preset**: Astro
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
   - **Environment variables**: `NODE_VERSION` = `22`
4. In the project settings, navigate to **Custom domains** > **Set up a custom domain** > enter `datnd.io.vn`.
5. Cloudflare will automatically configure DNS records and issue an SSL certificate.

### Method 2: GitHub Actions with Wrangler
1. Generate a Cloudflare API Token with `Cloudflare Pages: Edit` permissions.
2. In your GitHub repository settings, go to **Secrets and variables** > **Actions** and add:
   - `CLOUDFLARE_API_TOKEN`
   - `CLOUDFLARE_ACCOUNT_ID`
3. Every push to `main` will automatically build and deploy through `.github/workflows/cloudflare-pages.yml`.
