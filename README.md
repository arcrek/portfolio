# Nguyen Dang Dat (@arcrek) — Portfolio

A high-performance developer portfolio built with **Astro 5**, **Tailwind CSS v4**, and Google's **Material 3 (Material You)** design guidelines, deployed on **Cloudflare Pages** at **[datnd.io.vn](https://datnd.io.vn)**.

Written from the perspective of an ICT student and builder from Vietnam passionate about self-hosting, protocol reverse-engineering, and backend tooling.

## Key Features

- **Material 3 Design System**:
  - Surface container hierarchy (Lowest to Highest) for authentic visual elevation without heavy drop shadows.
  - Dynamic tonal palettes (Primary, Secondary, Tertiary, Surface, Outline Variant).
  - Material 3 Segmented Buttons, interactive Cards (Elevated & Outlined), and Assist Chips.
  - Zero-FOUC theme toggle supporting light and dark modes with local storage persistence.
- **Student Builder Persona**:
  - **Projects & Builds (`/`)**: Selected public projects (TMail, Telegram Order Bot, Outlook Graph Module, Canva Automation Suite) with technical breakdowns, architecture highlights, and telemetry stats.
  - **Homelab & Journey (`/lab`)**: Self-hosted stack (Proxmox VE, TrueNAS, Traefik, AdGuard Home, Docker, Jellyfin) and late-night iterative development cycle.
- **Build-Time GitHub Hydration**:
  - Languages, topics, stars, and repository metadata are fetched at build-time with offline cache fallback (`src/lib/github.ts`).
  - Privacy filter ensures only public, verified repositories are displayed.
- **Near-Zero Client JavaScript**:
  - Static HTML output generated by Astro with instant page loads and zero hydration overhead.
- **Cloudflare Pages Ready**:
  - Configured with `wrangler.jsonc` and `public/_headers` for edge caching and security headers.
  - Continuous deployment via Cloudflare Pages Git integration or GitHub Actions (`.github/workflows/cloudflare-pages.yml`).

## Getting Started

```bash

```

### 2. Local Development
```bash

```

### 3. Production Build
```bash
npm run build
```

### 4. Local Preview
```bash
npm run preview
```

### 5. Deploy to Cloudflare Pages via CLI
```bash
npx wrangler pages deploy ./dist --project-name portfolio
```

## Deploying to Cloudflare Pages with Custom Domain `datnd.io.vn`

### Method 1: Cloudflare Git Integration (Recommended)
1. Go to the [Cloudflare Dashboard](https://dash.cloudflare.com/) > **Workers & Pages** > **Create application** > **Pages** > **Connect to Git**.
2. Select repository `arcrek/portfolio`.
3. Set the build configuration:
   - **Framework preset**: Astro
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
   - **Environment variables**: `NODE_VERSION` = `22`
4. In the project settings, navigate to **Custom domains** > **Set up a custom domain** > enter `datnd.io.vn`.
5. Cloudflare will automatically configure DNS records and issue an SSL certificate.

### Method 2: GitHub Actions with Wrangler
1. Generate a Cloudflare API Token with `Cloudflare Pages: Edit` permissions.
2. In your GitHub repository settings, go to **Secrets and variables** > **Actions** and add:
   - `CLOUDFLARE_API_TOKEN`
   - `CLOUDFLARE_ACCOUNT_ID`
3. Every push to `main` will automatically build and deploy through `.github/workflows/cloudflare-pages.yml`.
